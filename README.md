# 🍥 Naruto Ninja App

Aplicativo mobile desenvolvido com **React Native e Expo**, como atividade prática do curso de Análise e Desenvolvimento de Sistemas, para a UC - CODING - MOBILE

O aplicativo permite explorar personagens do universo Naruto, consultar informações individuais e salvar personagens favoritos no armazenamento local do dispositivo.

## 📱 Funcionalidades

- **Início:** tela inicial do aplicativo.
- **Personagens:** consulta e exibição dos personagens utilizando uma API externa.
- **Detalhes:** visualização das informações de cada personagem selecionado.
- **Favoritos:** possibilidade de adicionar e remover personagens da lista de favoritos.
- **Persistência local:** os personagens favoritos permanecem salvos mesmo após fechar e abrir o aplicativo novamente.

## 🛠️ Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- React Native Paper
- React Navigation
- AsyncStorage
- API Tenrai

## 🌐 API utilizada

O aplicativo consome a API Tenrai para obter os personagens:

[https://api.tenrai.org/v1/anime/20/characters](https://api.tenrai.org/v1/anime/20/characters)


## ▶️ Como executar o projeto

**1. Clone o repositório:**

```bash
git clone https://github.com/alisoncrodrigues/naruto-ninja-app.git
```

**2. Entre na pasta do projeto:**

```bash
cd naruto-ninja-app
```

**3. Instale as dependências:**

```bash
npm install
```

**4. Inicie o Expo:**

```bash
npx expo start
```

Utilize o aplicativo Expo Go ou um emulador compatível para executar o projeto.
